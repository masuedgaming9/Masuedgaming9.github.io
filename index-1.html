02 // YOUR DEVICE

My Phone Games

Your personal game launcher list.

Add games that are already installed on your Android phone. This website cannot scan installed apps automatically, so you enter each game's name and (optionally) its Android package ID. The launch button will try to open the app; support varies by game and browser.

Tip: the package ID is not the game's display name. If you don't know it, add the game name only; you can still keep a personal list. Saved entries stay in this browser on this device.
